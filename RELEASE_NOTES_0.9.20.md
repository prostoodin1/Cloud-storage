# Cloud Storage 0.9.20

Главное обновление этой версии — более надёжное подключение небольшого домашнего сервера и нескольких Desktop Client.

- Client следит за всеми сохранёнными серверами, автоматически повторяет подключение после сетевых ошибок и показывает число активных соединений.
- При недоступном сервере виртуальный диск скрывается из Проводника и возвращается после восстановления связи.
- zrok2 определяется после обычной ручной установки, а также может быть скачан Core из официального релиза v2.0.4 с обязательной проверкой SHA-256. Аккаунт подключается одноразовым enable-токеном, который не сохраняется.
- Исправлена ложная ошибка `managed storage belongs to a different physical disk` после допустимого изменения системного идентификатора уже известного диска.
- В Manager различаются физические накопители и логические разделы, показаны Active / Idle / I/O / Error, улучшено получение модели и температуры Windows.
- Можно явно назначить любой раздел, включая C:, но опасные системные действия остаются заблокированными.
- Добавлены общие настройки новых дисков, подпись диска в Проводнике, массовые права чтения/добавления/изменения/удаления и безопасная кнопка удаления доступа пользователя.
- Client и Manager открывают папку журналов одной кнопкой; локальные и серверные события старше 30 дней удаляются автоматически.
- Скачанные файлы можно открывать автоматически, а вход нового устройства можно выполнить через Google OAuth, если администратор связал Google Client ID и email пользователя.
- Элементы настроек получили подсказки, фоновые задачи ограничивают число потоков по доступным ядрам CPU.
- Имена объектов резервного снимка стали короче, поэтому повторная проверяемая копия не упирается в ограничение длины пути Windows.

Android и iOS в выпуск 0.9.20 не входят и остаются на версии 0.9.14.
