# План разработки

## Выполнено

### Этап 1 — Server Manager Beta 0.1

- интерфейс, реальные диски и сохранение политик;
- необязательная первоначальная настройка;
- состояния паузы, обслуживания и отключения;
- отсутствие скрытых изменений данных.

### Этап 2 — Server Core Beta 0.2

- независимый фоновый процесс, Windows Service Host и systemd unit;
- локальный API v1, SQLite, пользователи и личные пространства;
- одноразовые приглашения, Argon2id и подтверждение устройств;
- атомарная загрузка, скачивание, версии и мягкое удаление;
- применение приоритета, заполнения и резерва подключённых дисков.

### Этап 3 — Desktop Client Alpha 0.3

Завершён настольный клиент:

- отдельный кроссплатформенный Client App;
- код подключения, пароль, pending-состояние и подтверждение;
- просмотр пространств и файлов;
- фоновая загрузка/скачивание и локальный офлайн-каталог;
- автоматическая проверка подключения;
- защищённое локальное хранение токена;
- вкладка вопросов и ответов в Server Manager и Desktop Client;
- локальный помощник с общей SQLite-базой знаний и учётом вопросов без ответа;
- отдельный HTTPS-вход для LAN, постоянный сертификат и закрепление отпечатка;
- обнаружение сервера в локальной сети и полное приглашение для клиента;
- устойчивые передачи с паузой, повтором после обрыва и продолжением после перезапуска;
- индекс офлайн-кэша с SHA-256 и безопасным разрешением конфликтов;
- подключение каталога к Проводнику Windows и файловому менеджеру Linux;
- автозапуск, системный трей и Client Installer.

### Этап 4 — хранение и автоматизация

- дополнительные диски, правила заполнения и режимы обслуживания;
- проверяемый перенос данных с сохранением исходной страховочной копии;
- ручные и автоматические резервные снимки;
- зеркальные реплики, автоматическое восстановление и чтение при отказе основного объекта;
- постоянное расписание снимков и политика хранения — готовы в Alpha 0.5.0a3;
- пробное восстановление базы и каждого объекта на основной диск — готово в Alpha 0.5.0a3;
- безопасная ротация только успешно проверенных снимков — готова в Alpha 0.5.0a3.

## В работе

### Этап 5 — надёжность сервера и удалённый доступ

- постоянная быстрая диагностика, история инцидентов и автоматическое закрытие устранённых проблем — готовы в Alpha 0.5.0a1;
- полная проверка текущих объектов, версий и зеркал по SHA-256 — готова в Alpha 0.5.0a1;
- восстановление прерванных диагностических заданий — готово в Alpha 0.5.0a1;
- проверяемое восстановление отсутствующих/повреждённых объектов из снимка — готово в Alpha 0.5.0a2;
- управляемый глобальный аварийный режим только чтения — готов в Alpha 0.5.0a2;
- удалённый защищённый доступ и несколько серверов — после модели доверия и дополнительной защиты администратора.
