# Аудит Idea #003

Дата проверки: 2026-08-11. Проверенная версия: 0.9.7.

Issue нельзя закрывать: базовая экосистема и все шесть пользовательских компонентов существуют, но несколько обязательных требований ещё не реализованы полностью.

## Выполнено

- Server Manager, Server Core/Windows Service, Desktop Client и оба Windows-установщика собираются и проходят автоматические тесты.
- Реализованы пользователи, роли, одноразовые коды подключения, подтверждение и отзыв устройств, TLS pinning, аудит и защищённое хранение токенов.
- Реализованы логические пространства, передача файлов, сетевой диск Windows, локальный кэш, офлайн-файлы и несколько серверных профилей ПК-клиента.
- Реализованы роли дисков, пороги заполнения, переносы, резервные копии, зеркала, обслуживание, режим всего сервера «только чтение» и безопасная автоматизация.
- Реализованы Mobile Client и Mobile Server Control, фоновые передачи, автокопирование фото, офлайн-скачивание и ограничение автокопирования сетью Wi-Fi.
- Реализованы управление Docker-контейнерами и SSH через защищённые административные маршруты.
- Версия 0.9.7 не допускает накопления второго экземпляра Manager, Desktop Client, Server Core/Service, виртуального диска, установщиков и параллельной мобильной фоновой задачи.

## Не выполнено полностью

1. **Linux-поставка.** CI проверяет и собирает переносимые PyInstaller-каталоги на Linux, но нет полноценных Linux-установщиков/пакетов, интеграции службы и виртуального диска, равнозначных Windows-версии. Требование «все приложения под Windows / Linux» не закрыто.
2. **Двухфакторная защита администратора.** Есть пароль, подтверждение устройства, короткая внешняя сессия и биометрическая защита телефона, но нет отдельного второго фактора TOTP/WebAuthn или резервных кодов.
3. **Ограничения ПК-клиента.** В профиле Desktop Client нет лимитов скорости загрузки/скачивания и правил запрета работы через выбранные типы сетей.
4. **Mobile Client.** Нет переименования и перемещения файлов/папок, пользовательской сортировки, встроенного просмотра фото/видео/документов, отдельной истории файловых операций и переключения между несколькими сохранёнными серверами.
5. **Mobile Server Control.** Мобильный менеджер предоставляет безопасную сводку, устройства и аварийный read-only, но не весь заявленный набор управления пользователями, резервными копиями, зеркалами, отдельными дисками и обслуживанием.
6. **Расширенная телеметрия дисков.** Модель данных предусматривает температуру, скорость, нагрузку и часы работы, однако текущий сборщик ОС заполняет главным образом модель, серийный номер, интерфейс, файловую систему и объём. SMART/температура/скорость/наработка и история состояния требуют отдельного backend.
7. **Системный запрет запуска загруженных файлов.** Core не предоставляет маршрутов исполнения и хранит объекты непрозрачно, но read-only сам по себе не является гарантией non-executable на Windows. Нужна проверяемая политика ACL/AppLocker/WDAC либо изолированное файловое хранилище с эквивалентной гарантией.
8. **Установщики.** Есть установка, обновление, удаление, служба, автозапуск, WinFsp и правила брандмауэра, но нет полноценного пользовательского режима диагностики/восстановления повреждённой установки и полного сетевого/system preflight.

## Условие закрытия

Idea #003 можно закрыть после реализации и проверки всех восьми пунктов выше на поддерживаемых платформах. До этого issue должна оставаться открытой.
