# Cloud Storage 0.10.2

Исправлено повторное появление блокировки серверных ключей при обновлении старой установки.

- На время защищённого обновления служба переводится в отключённый режим, а её recovery-действия
  временно снимаются. Старый service wrapper больше не может автоматически перезапуститься между
  остановкой и копированием `core-secrets.json`.
- Server Manager, Container Manager, Core, Legacy Core и старый service wrapper завершаются до
  резервного копирования.
- Права `core-secrets.json` восстанавливаются по стабильным SID для SYSTEM и Administrators без
  зависимости от языка Windows.
- Если установка отменена или резервная копия не создана, автоматический запуск и recovery службы
  возвращаются автоматически.
- При редкой повторной ошибке окно теперь показывает конкретную причину Windows.

Выпуск также включает исправление постоянного установщика из 0.10.1: проверенный скачанный Setup
переиспользуется по размеру и SHA-256 вместо замены работающего EXE.
