# Cloud Storage 0.10.6

Срочное обновление стабильности клиента и управления аккаунтом.

- Во вкладке «Аккаунт» логин можно менять без повторного подключения устройства.
- Кнопка «Создать новый пароль» принимает любой непустой пароль без требований к сложности.
- Текущие логин и пароль можно посмотреть и скопировать; на Windows они хранятся в защищённом хранилище текущего пользователя.
- После первого pairing доверенный токен устройства работает одинаково в локальной сети и через интернет. Дополнительный истекающий парольный сеанс больше не прерывает передачи.
- Удаление файла одним нажатием перемещает его в серверную корзину без повторного диалога.
- На главной странице Server Manager добавлен график загрузки и скачивания за 24 часа, 7 дней, 30 дней или всё время.
- Сохранена совместимость с сервером 0.10.5 при изменении аккаунта, если старый пароль уже сохранён клиентом.

Мобильные приложения в этом выпуске не изменялись.
