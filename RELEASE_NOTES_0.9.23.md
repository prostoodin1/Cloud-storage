# Cloud Storage 0.9.23

Исправляющий выпуск Desktop Client, Server Manager, Core и установщиков Windows.
Мобильные приложения не изменены.

- Постоянные установщики Client и Server теперь открывают обычный мастер Setup:
  пользователь видит отдельный выбор создания ярлыка на рабочем столе. В обоих
  случаях ярлык по умолчанию не выбран.
- Автоматическая установка обновления из приложения остаётся тихой. Перед запуском
  по-прежнему повторно проверяются продукт, версия, имя, размер и SHA-256 пакета.
- Исправлено сохранение букв виртуальных дисков по логическому пространству:
  буквы больше не сдвигаются после сохранения настроек и перезапуска Client.
- Go-супервизор больше не останавливается после отклонённого или неуспешного
  запроса административного завершения. Остановка выполняется только после
  подтверждённого Core ответа 200.
- Расширена проверка готовых пакетов: папки и файлы через Desktop API и браузерную
  сессию, публичные ссылки, изоляция личных пространств, архив/восстановление и
  сохранение сессий после перезапуска.

Все существующие настройки, пользователи, пространства и файлы сохраняются.
Формат базы данных в этом исправляющем выпуске не менялся.

Проверено: 191 Python-тест, Go Core, Go-драйвер, 23 проверки готовых пакетов,
15 проверок настоящего WinFSP-диска и видимый браузерный сценарий с созданием
папки, загрузкой, предпросмотром и скачиванием. Отдельная чистая Windows-машина,
подключение из внешней сети, SMTP/Gmail и Docker в этом прогоне не проверялись.
Подробный отчёт: `docs/QA-2026-09-07.md`.
