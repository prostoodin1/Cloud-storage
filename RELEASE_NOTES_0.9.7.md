# Cloud Storage 0.9.7 — один экземпляр каждого приложения

Исправлено накопление процессов после повторных запусков.

- Server Manager и Desktop Client работают в одном экземпляре на пользователя;
- повторный запуск поднимает уже открытое окно;
- Server Core и Windows Service используют общий PID-guard;
- Desktop Client держит только один активный процесс виртуального диска;
- `CloudStorageDrive.exe` дополнительно защищён системным Windows mutex;
- установщики Server и Client нельзя запустить параллельно второй копией;
- мобильная фоновая задача не запускает второй параллельный worker;
- smoke-тесты используют отдельные временные single-instance endpoints и не мешают запущенным приложениям.
