# Cloud Storage 0.7.0 — Stage 7

Полностью завершён Windows-этап перед мобильными приложениями.

- Server Setup устанавливает Manager, Core и автоматически запускаемую Windows-службу.
- Client Setup включает WinFsp и настоящий диск Cloud Storage в Проводнике.
- Для каждого серверного профиля доступна отдельная буква и автоподключение при входе.
- Диск поддерживает ленивое чтение, запись, папки, переименование и удаление через Core API.
- Manager и Client проверяют и устанавливают обновления из новой вкладки.
- Манифесты обновлений подписаны Ed25519; размер и SHA-256 пакета проверяются дважды.
- Обновление и обычное удаление сохраняют базу, пользователей, настройки, токены и файлы.

Важно: установщики требуют Windows 10 1809+ x64 и права администратора. Установщики пока не
имеют коммерческой Authenticode-подписи, поэтому Windows SmartScreen может показать издателя
как неизвестного; встроенная проверка обновлений использует отдельную Ed25519-подпись.
