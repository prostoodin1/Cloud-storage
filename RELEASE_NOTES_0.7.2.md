# Cloud Storage 0.7.2 — Expanded automation

Версия завершает расширение серверной автоматизации перед финальным мобильным этапом.

- Добавлены расписание и события backup, restore, зеркал, обслуживания и новых устройств.
- Добавлены полная диагностика, запуск backup, восстановление зеркала и перезапуск шлюза.
- Планировщик можно включать, приостанавливать и перенастраивать без перезапуска Core.
- Предварительная проверка показывает совпадения и cooldown без выполнения действий.
- Manager предлагает только безопасные сочетания условия и действия; Core проверяет их повторно.
- Старые правила и история транзакционно мигрируют в новую SQLite-схему.
- Результаты автоматизации отображаются понятным текстом и сохраняются в аудите.

Произвольные команды, скрипты и URL по-прежнему запрещены. Опасный read-only требует
явного подтверждения и разрешён только для критического диагностического события.
