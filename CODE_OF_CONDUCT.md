# Правила общения

Участники Cloud Storage общаются уважительно и обсуждают конкретную проблему,
поведение программы и проверяемые результаты. Опыт, язык и платформа участника
не должны становиться поводом для оскорблений.

Не допускаются угрозы, преследование, дискриминация, публикация чужих личных
данных и секретов, спам и намеренное нарушение работы чужих систем.

Владелец репозитория и сопровождающие могут попросить изменить сообщение,
скрыть или удалить нарушающий правила контент либо ограничить участие.

О проблеме можно сообщить владельцу [prostoodin1](https://github.com/prostoodin1)
в issue, не раскрывая личных данных и подробностей преследования публично;
при необходимости сначала запросите закрытый канал. Уязвимости направляйте
отдельно по [SECURITY.md](SECURITY.md).
