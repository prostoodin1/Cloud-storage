# Cloud Storage Mobile 0.8.0

Один React Native/Expo-клиент для Android и iPhone. Обычный пользователь видит файлы, передачи и настройки. У подтверждённого пользователя с ролью `admin` дополнительно появляется вкладка «Сервер» с безопасным мониторингом, подтверждением/отзывом устройств и включением режима только чтения.

## Что работает

- вход по логину и паролю либо резервному одноразовому коду;
- отдельное ручное подтверждение каждого нового телефона в Server Manager;
- папки, загрузка файлов и фотографий, скачивание, удаление в корзину;
- постоянная очередь, возобновляемая отправка блоками и системная фоновая докачка;
- сохранение скачанных файлов офлайн и передача их в другие приложения;
- защищённое хранение токена устройства и интернет-сессии в Keychain/Keystore;
- администраторская сводка без открытия обычного Manager API наружу.

Пароль не записывается на телефон. Смена пароля в Manager прекращает действующие интернет-сессии, но уже подтверждённое устройство остаётся доверенным, пока администратор его не отзовёт.

## Локальный запуск

Нужны Node.js 22 и pnpm 11.

```bash
cd mobile
pnpm install
pnpm start
```

Для нативной локальной сборки Android потребуется Android Studio/JDK, для iOS — macOS, Xcode и Apple-подпись:

```bash
pnpm android
pnpm ios
```

GitHub Actions проверяет TypeScript и обе JS-сборки, а также создаёт устанавливаемый отладочный Android APK как artifact `CloudStorage-Mobile-0.8.0-android-preview`. Для публикации в Google Play/App Store нужно создать собственные ключи подписи. EAS можно подключить командами `eas login` и `eas init`; идентификатор чужого Expo-проекта в репозитории намеренно не зашит.

## Адрес сервера

На реальном телефоне `127.0.0.1` означает сам телефон, а не компьютер с сервером. Для домашней сети нужен доступный телефону HTTPS-адрес Core. Для интернета рекомендуется публичный HTTPS-адрес zrok. Текущий мобильный клиент доверяет системной цепочке сертификатов и запрещает обычный HTTP, кроме loopback; поддержка закрепления самоподписанного LAN-сертификата остаётся отдельной задачей перед публичным магазинным релизом.

После первого ввода логина и пароля телефон получает только pending-токен. Доступ к файлам откроется после подтверждения устройства администратором. Для внешнего адреса после подтверждения приложение дополнительно попросит пароль, чтобы выпустить ограниченную интернет-сессию.
