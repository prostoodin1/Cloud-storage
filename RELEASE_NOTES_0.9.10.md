# Cloud Storage 0.9.10 — исправление центра обновлений

Версия 0.9.10 восстанавливает установку обновлений из вкладки Server Manager и Desktop Client.

- В GitHub Release снова публикуются подписанные каталоги версий клиента и сервера.
- Установщик запускается через системный Windows UAC (`runas`), поэтому ошибка CreateProcess 740 больше не блокирует обновление.
- После скачивания вкладка показывает полный путь к проверенному EXE.
- Добавлена кнопка «Показать установщик» для ручного запуска из Проводника.
- Перед запуском по-прежнему повторно проверяются размер и SHA-256 установщика.
