# Cloud Storage 0.10.5

- Убраны требования к сложности и минимальной длине пароля. При первом подключении создаётся читаемый цифровой пароль вида `4821-0365-7194`.
- В Manager пароль, созданный или сброшенный администратором, по-прежнему хранится отдельно через защиту Windows и доступен для копирования.
- Загрузка обновлений, cloudflared и Docker теперь сопровождается видимым индикатором выполнения.
- Мастер Cloudflare открывает Zero Trust, принимает публичный HTTPS hostname и tunnel token, включает удалённое pairing и применяет настройку туннеля.
- Клиент принимает актуальные CS3-коды и старые форматы приглашений; настройки и база продолжают мигрировать поверх существующей установки.
- Для виртуальных дисков добавлена отдельная синяя иконка Cloud Storage Drive.
- Тихое обновление из Client и Server Manager после успешной установки автоматически запускает новую версию приложения.
- Подправлены минимальные размеры элементов и перенос длинных пояснений в окнах подключения и настроек.
