# Cloud Storage 0.9.9 — Native Go Core

Версия 0.9.9 исправляет установленную Windows-службу 0.9.8 и начинает безопасный перенос серверного ядра на Go без изменения API и потери данных.

## Исправления запуска

- `CloudStorageServerCore.exe` и `CloudStorageServerService.exe` теперь являются нативными Go-приложениями.
- Windows Service больше не зависит от консольного formatter Uvicorn.
- Вместо ненадёжной проверки номера PID используется системный mutex Go Core и проверка реальной идентичности compatibility-процесса.
- Устаревший `core.pid`, чей номер уже принадлежит `svchost.exe` или другой программе, безопасно удаляется.
- Go-watchdog перезапускает внутренний API после аварийного завершения с ограниченной задержкой.
- Холодному запуску даётся до 30 секунд; диагностика показывает состояние службы и последние записи журнала.
- Исправлена декодировка локализованного вывода `sc.exe` через OEM-кодировку Windows.

## Совместимость и безопасность

- Все существующие маршруты API v1, база SQLite, пользователи, устройства, файлы, резервные копии, автоматизации, Docker, SSH и zrok сохранены.
- Внутренний compatibility engine слушает отдельный loopback-порт и недоступен извне.
- Публичный локальный API проходит через Go Core; LAN/remote TLS продолжают работать через совместимый слой во время переноса к 1.0.0.
- Команда выключения корректно завершает Go Core и дочерний процесс без накопления экземпляров.
- Установщик останавливает старую службу, создаёт резервную копию базы и обновляет конфигурацию службы на новую реализацию.

## Проверки

- Python lint и полный набор pytest.
- Go format, unit tests и vet.
- End-to-end запуск Go Core → compatibility engine → API health → штатный shutdown.
- Smoke-тесты Manager, Desktop Client, Core, Service и виртуального диска.
- Подписанные Android APK собираются GitHub Actions отдельно для Client и Manager.

Полный перенос бизнес-логики из compatibility engine в нативные Go-модули продолжится к версии 1.0.0 без изменения клиентского протокола.
