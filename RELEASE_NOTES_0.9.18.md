# Cloud Storage 0.9.18

Удалённый доступ переведён на актуальный zrok2. Новые установки запускают бинарник
`zrok2`, разрешают его переменные окружения `ZROK2_*` и создают обычный публичный
туннель командой `zrok2 share public --headless`.

Постоянное публичное имя теперь подключается через namespace `public` и параметр
`-n public:<имя>`. Это заменяет удалённую из zrok2 команду `share reserved`.
Перед использованием постоянного имени его нужно один раз создать командой
`zrok2 create name -n public <имя>`.

Сохранённое стандартное значение `zrok` автоматически мигрирует на `zrok2`.
Явно заданный полный путь к старому zrok v1 продолжает использовать совместимую
команду, поэтому ручные установки не ломаются без предупреждения. Серверная база,
пользователи, клиентские подключения и файлы при обновлении сохраняются.

Android APK не изменялись и остаются на версии 0.9.14.
