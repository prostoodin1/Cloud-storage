# Cloud Storage 0.10.8b4

Beta-релиз от 30 октября 2026 для Windows x64.

## Изменения

- Большие resumable-загрузки завершаются через короткие запросы опроса: длительная проверка SHA-256 не ограничивается одним HTTP-запросом на 30 секунд. Windows-клиент показывает «Проверка файла на сервере».
- Повторные запросы завершения используют одну работающую финализацию. Разрыв соединения ожидающего клиента не отменяет начатую проверку/сохранение. Число одновременных финализаторов ограничено вместе с остальными загрузками.
- Убрана обязательная write-транзакция SQLite из каждого запроса аутентификации; актуальный статус устройства проверяется без кэширования доверия. Запись присутствия устройства ограничена по частоте.
- WAL устанавливается при инициализации БД. Промежуточный сетевой прогресс пропускает временную занятость writer; обязательные подтверждения блоков и завершение остаются транзакционными.
- Временная занятость SQLite до начала ответа сообщает `503 database_busy` и `Retry-After`, вместо необработанного `500`.
- Мобильные исходники поддерживают опрос завершения и проверяют владение заданием очереди. APK/IPA в этот Windows-релиз не входят.
- Включены прежние исправления Range/If-Range, SHA-256, восстановления маршрутов, очередей и догрузки установщиков из подготовки b3.

## Скачать

- `CloudStorage-Client-Setup-0.10.8b4-windows-x64.exe` — полный установщик клиента; включает компонент WinFsp для виртуального диска.
- `CloudStorage-Server-Setup-0.10.8b4-windows-x64.exe` — полный установщик сервера, менеджеров, ядра и службы.
- `CloudStorage-Desktop-Client-0.10.8b4-windows-x64.zip` — переносной комплект клиента; для диска нужен установленный WinFsp.
- `CloudStorage-Server-Manager-0.10.8b4-windows-x64.zip` — переносной комплект серверных компонентов.
- `CloudStorage-Source-0.10.8b4.zip`, `SHA256SUMS.txt` и отчёт проверки — исходники точного коммита и контрольные суммы.

Для прямой установки используйте versioned Setup EXE из этого релиза. Существующие сетевые bootstrap-установщики и каталоги стабильного автообновления этой публикацией не заменяются.

## Проверки и ограничения

Пройдены 261 Python-тест, 12 мобильных протокольных тестов и TypeScript, а также Go test/vet для ядра и диска. Новые Windows-пакеты прошли 28/28 проверок напрямую через compatibility engine, 30/30 через нативное ядро и 7/7 на настоящем виртуальном диске. Среди регрессий — реальный HTTP-вызов с искусственной задержкой проверки 31,1 секунды, конкурирующие опросы, обрыв ожидающего запроса, ограничения нагрузки, неверный SHA-256 и занятая SQLite. Итоговые проверки перечислены в приложенном отчёте `b4-release-20261030.json`.

Установщики собраны, версии их ресурсов проверены. Установка/обновление поверх действующей службы в этой работе не выполнялись: пакеты проверялись в отдельных каталогах.

Повторные передачи 1/10/20/30 ГБ на b4, длительная нагрузка, независимые физические устройства и реальный интернет ещё не проверены. Скорость 60–200 МБ/с этим релизом не подтверждается. Прежние измерения опубликованы отдельно и относятся к предыдущему коду.

Windows-приложения и установщики не имеют Authenticode-подписи издателя Cloud Storage; SHA-256 в приложенном списке проверяет соответствие скачанного файла опубликованному.
