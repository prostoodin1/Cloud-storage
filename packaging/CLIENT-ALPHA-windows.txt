CLOUD STORAGE DESKTOP CLIENT — 0.9.0
================================================

Этап 7 завершён: клиент устанавливает всё необходимое для дисков в Проводнике и обновляется из приложения.

Как попробовать на серверном компьютере
----------------------------------------
1. Запустите Server Manager Beta 0.2 и Server Core.
2. Создайте пользователя с логином и временным паролем.
3. Запустите CloudStorageClient\CloudStorageClient.exe.
4. Оставьте адрес http://127.0.0.1:8765, введите логин, пароль и название компьютера.
5. Подтвердите появившееся устройство в Server Manager.
6. В клиенте нажмите «Проверить подтверждение» или подождите до 10 секунд.

После подтверждения станут доступны личное пространство, загрузка, скачивание,
серверная корзина и локальный офлайн-каталог.

Что уже доступно
---------------
- защищённое LAN-подключение с закреплением SHA-256-отпечатка;
- докачка, пауза и продолжение передач после перезапуска;
- офлайн-каталог и интеграция с Проводником;
- серверные проверяемые переносы, резервные снимки и зеркальные реплики;
- постоянная диагностика Core, история инцидентов и полная проверка SHA-256.
- проверяемое восстановление повреждённых объектов и аварийный режим сервера только чтения.
- расписание резервных снимков, пробное восстановление и безопасная ротация копий.
- несколько серверных профилей с отдельным TLS-отпечатком и токеном для каждого подключения.
- защищённый удалённый HTTPS-доступ без публикации административного API.
- отдельный настоящий Windows-диск для каждого сервера с автоматическим переподключением;
- ленивое скачивание, создание папок, запись, переименование и удаление через Core;
- проверка и установка подписанных обновлений из вкладки «Обновления».

Android/iPhone-клиент 0.9.0 использует тот же аккаунт с отдельным подтверждением телефона, фотокопированием и мобильным управлением сервером.

Токен устройства шифруется Windows DPAPI и не хранится в обычном JSON-файле.
