# Cloud Storage 0.10.4

Добавлена единая система пользовательских аккаунтов для Desktop Client и веб-версии.

- Первое подключение по пятиминутному коду автоматически создаёт уникальные логин и пароль.
- Client показывает данные один раз, копирует их в буфер и продолжает входить автоматически
  с защищённым ключом устройства.
- Новая вкладка «Аккаунт» позволяет владельцу в любое время изменить и логин, и пароль.
- Веб-версия принимает логин и пароль существующего аккаунта или динамический код для первого входа.
- Переключатель «Это доверенное устройство» управляет постоянной защищённой браузерной сессией.
  Без него используется cookie текущего сеанса браузера.
- Пароли хранятся только как Argon2id-хеши; постоянный пароль не помещается в cookie или ссылку.
- После изменения учётных данных браузерные сессии завершаются, а доверенный Desktop Client
  остаётся подключённым.
- Логин проверяется на уникальность, а старые серверные базы обновляются без удаления данных.
