# Приложения Cloud Storage

Это единая точка входа в шесть частей проекта. Нумерация сохраняет понятный порядок на странице GitHub.

| № | Раздел | Назначение | Готовая сборка |
|---:|---|---|---|
| 1 | [Установщик сервера](01-server-installer/README.md) | Ставит Manager, Core и системную службу | Windows Setup |
| 2 | [Установщик клиента](02-client-installer/README.md) | Ставит Desktop Client, диск Проводника и зависимости | Windows Setup |
| 3 | [Клиент на ПК](03-desktop-client/README.md) | Файлы, передачи, офлайн-каталог и диск | Windows portable |
| 4 | [Менеджер на ПК](04-server-manager/README.md) | Пользователи, диски, автоматизация и сервер | Windows portable |
| 5 | [Телефонный клиент](05-mobile-client/README.md) | Файлы, фото, поиск и передачи | Android/iPhone |
| 6 | [Телефонный менеджер](06-mobile-manager/README.md) | Защищённое управление сервером | Android/iPhone |

GitHub не поддерживает пользовательские верхние вкладки внутри одного репозитория. Эти каталоги выполняют ту же задачу: каждый открывается как отдельный мини-проект со своими файлами, README и историей коммитов, а общий код не дублируется.
