# Cloud Storage 0.9.11 — подключение по коду и контейнерные пространства

Версия 0.9.11 исправляет перезапуск серверного ядра и возвращает основной сценарий подключения без ручного ввода IP.

- Windows-служба теперь полностью доходит до состояния `STOPPED` перед повторным запуском; гонка, из-за которой API не отвечал за 30 секунд, устранена.
- В Server Manager добавлена отдельная вкладка «Подключение» и такой же генератор в настройках.
- Единый код `CS1.…` содержит адрес сервера, одноразовый код, TLS-отпечаток и логин; Desktop Client подставляет их автоматически.
- В Desktop Client первая вкладка называется «Подключиться», а сценарий по коду расположен первым.
- Локальный и интернет-адреса выбираются явно. Интернет-код доступен только при рабочем zrok или публичном HTTPS-входе.
- Адрес сервера в браузере показывает состояние службы и ссылку на health API.
- Контейнеры скриптов и ботов вынесены в отдельный Container Manager с карточками боксов, настройкой CPU, RAM, временного пространства, таймаута и сети.
- Контейнерные боксы теперь можно создавать, редактировать, запускать и удалять через постоянный Server Core API.
- Отдельный Container Manager входит в установщик и ZIP Server Manager, не создавая седьмой пользовательский дистрибутив.
