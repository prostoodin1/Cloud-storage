# История изменений

## 0.10.8b6 — 7 ноября 2026, beta

- Графические Client и Server Manager сохраняются; CLI добавлена отдельно для ИИ.
- Manager показывает готовность хранилища принимать файлы и причины блокировки записи.
- Клиент объясняет ошибки ёмкости и недоступности дисков на русском.
- Завершение upload-сессии и метаданные файла фиксируются одной транзакцией.
- Восстановление после аварии, защита опубликованных/архивных версий и обработка I/O.
- CLI: JSON, диагностика, список файлов, загрузка с checkpoint и скачивание с SHA-256.

[Release notes](RELEASE_NOTES_0.10.8b6.md) · [CLI](docs/cli.md).

## 0.10.8b5 — 6 ноября 2026, beta

- Автоматическая проверка, загрузка и установка обновлений Windows Client и Manager
  включены по умолчанию для профилей без сохранённых настроек обновления.
- Установка ждёт завершения передач; приложение запускается снова после установки.
- Отмена UAC больше не останавливает Core; сетевые ошибки оставляют приложение доступным.
- Счётчики активных серверных передач учитывают всю историю, включая записи вне страницы UI.
- Отдельный подписанный канал v2 и ключ выпуска в зашифрованном хранилище Windows;
  для перехода со старого канала нужен один запуск Setup b5.

[Подробности и ограничения](docs/automatic-updates.md).

[Release notes](RELEASE_NOTES_0.10.8b5.md).

## 0.10.8b4 — 30 октября 2026, beta

- Опрос долгого завершения загрузки, отдельный статус проверки файла.
- Одна финализация для повторных запросов, ограничение параллельной работы.
- Меньше обязательных SQLite-записей при аутентификации и передаче прогресса.
- Возобновление передач, SHA-256, Range/If-Range и исправления подготовки b3.

[Release notes](RELEASE_NOTES_0.10.8b4.md) ·
[GitHub release](https://github.com/prostoodin1/Cloud-storage/releases/tag/v0.10.8b4) ·
[Отчёт проверок](validation/b4-release-20261030.json)
