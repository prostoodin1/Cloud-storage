# Cloud Storage 0.9.6 — Docker и SSH

Патч серверного менеджера Idea 4.

## Что добавлено

- отдельная вкладка «Docker и SSH» в Server Manager;
- фоновая загрузка Docker Desktop с официального адреса Docker;
- проверка Authenticode-подписи установщика перед запуском;
- отображение состояния Docker CLI и контейнерного движка;
- установка Windows OpenSSH Server из интерфейса;
- SSH-вход только по публичному ключу для одного локального администратора;
- проверка `sshd_config` перед перезапуском службы;
- отдельное правило Windows Firewall только для профиля «Частная сеть»;
- кнопка безопасного отключения SSH без удаления ключей и резервной копии;
- исправлен код ошибки Windows 740 при запуске Server Manager после установки.

Контейнеры для скриптов и ботов используют уже существующие безопасные ячейки: read-only
файловая система, лимиты CPU/RAM/диска/процессов, тайм-аут и выключенная сеть по умолчанию.
