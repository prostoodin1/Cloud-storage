# Cloud Storage 0.10.8 beta 2

Исправляющий beta-релиз после полного аудита клиента, сервера, веб-доступа и Windows-пакетов.

- Веб-вход теперь ограничивает перебор паролей по учётной записи и источнику подключения. После пяти неправильных попыток вход временно блокируется с HTTP 429.
- Сохранена возможность использовать простой пользовательский пароль, но внешний вход больше нельзя бесконтрольно нагружать Argon2-проверками.
- Версия Native Go Core автоматически синхронизируется с версией приложения во время сборки и проверяется до упаковки.
- Пакетный QA теперь совместим с Windows PowerShell 5.1 и PowerShell 7.
- Добавлены CodeQL для Python, Go и JavaScript/TypeScript и еженедельные Dependabot-проверки зависимостей.
- Сборка поддерживает Authenticode-подпись всех Windows EXE и проверяет её при наличии сертификата издателя.
- Повторно проверены pairing, веб-сессия, создание папок, загрузка, скачивание, публичные ссылки, изоляция пользователей, перезапуск Core и настоящий WinFsp-диск.
- Виртуальный диск использует реальную квоту пространства и не показывает фиксированные 8 ТБ.

Автоматическая проверка исходников: 214 Python-тестов и Ruff. Мобильные приложения в этом beta-релизе не пересобирались.

Windows EXE этого выпуска могут оставаться без Authenticode, пока для проекта не настроен сертификат code signing. Подписанные Ed25519-каталоги обновлений, размер и SHA-256 пакетов проверяются как прежде.
