CLOUD STORAGE 0.10.5 — WINDOWS QUICK START
==========================================

Обычная установка
-----------------
1. Запустите стабильный Server Installer от имени администратора.
2. Установщик обновляет приложение, сохраняя базу, пользователей, файлы и настройки.
3. Откройте Server Manager и убедитесь, что Core отвечает на проверку состояния.
4. В разделе «Подключение» создайте динамический код; он меняется каждые пять минут.
5. На компьютере пользователя в Desktop Client введите код и завершите pairing.
6. Для доступа через интернет настройте remotely-managed Tunnel в Cloudflare, укажите
   публичный HTTPS hostname, установите cloudflared из Manager и добавьте Tunnel token.

В 0.10.5 первое подключение по динамическому коду автоматически создаёт пользователю
логин и пароль. Они показываются один раз и копируются в буфер. Во вкладке «Аккаунт»
Desktop Client пользователь в любое время может сменить логин и пароль. Веб-версия
поддерживает вход по этим данным и отдельный режим доверенного устройства.

Обновление сохраняет данные. Перед первой миграцией Core создаёт и проверяет резервную
копию SQLite. Не удаляйте каталог данных сервера при переустановке.

Мобильные приложения остаются на предыдущей версии и в рамках 0.10.5 не пересобираются.
