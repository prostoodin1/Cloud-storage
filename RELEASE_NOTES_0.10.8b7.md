# Cloud Storage 0.10.8b7

Предварительный выпуск для Windows x64. Для установки скачайте отдельный Client Setup или Server Setup из Assets.

- Manager и Desktop Client получили тёмную оболочку с янтарными акцентами и меню разделов внизу. Manager при запуске показывает этапы проверки и открывает «Главную» с трафиком, состоянием хранилища и активными передачами.
- Manager выдаёт код с единым публичным HTTPS-адресом после проверки настроенного Cloudflare Tunnel. Desktop Client различает недоступность шлюза и недействительный доступ устройства, сохраняя вход при временном сбое.
- Веб-клиент отправляет файл порциями и возобновляет загрузку с подтверждённой позиции. При повторном выборе проверяются уже принятые части. Серверный лимит по умолчанию — 75 ГБ на файл при достаточной квоте и месте. Незавершённые загрузки хранятся семь суток.

## Установка и ограничения

- Полный локальный прогон исходников Windows прошёл: 297 тестов.
- Установка b7 вручную из этого релиза. Подписанный канал автообновлений сохраняет предыдущую версию.
- Реальная передача 75 ГБ через Cloudflare Tunnel с другого устройства и штатное обновление поверх действующей установки b6 ещё не подтверждены. Установщики без Authenticode-подписи издателя.
- Полный редизайн Manager и критерии приёмки из #37 и #38 остаются в работе.
