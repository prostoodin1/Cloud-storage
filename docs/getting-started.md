# Первое подключение

Актуальные файлы Windows b4 находятся на [странице релиза](https://github.com/prostoodin1/Cloud-storage/releases/tag/v0.10.8b4).
Для обычной установки выберите `Client-Setup-0.10.8b4` и `Server-Setup-0.10.8b4`.
Перед обновлением сохраните собственную резервную копию важных данных и серверной базы.

## Сервер и клиент

1. На серверном компьютере запустите Server Setup и откройте Server Manager.
2. В Manager проверьте состояние ядра и настройте накопитель для хранения.
3. Создайте пользователя с нужной квотой и правами, затем получите приглашение
   в разделе подключения. Приглашение передавайте только нужному человеку.
4. На клиентском компьютере установите Client. WinFsp нужен для виртуального
   диска в Проводнике; полный Client Setup содержит этот компонент.
5. Используйте приглашение в Client. Если устройство ожидает подтверждения,
   подтвердите его в Manager. Внешний вход может дополнительно потребовать пароль.
6. Передайте небольшой файл в обе стороны и проверьте его открытие.

При смене компьютера или переустановке учитывайте отдельное подтверждение нового
устройства. Подключённый диск зависит от работающего Client и доступного сервера.

## Сеть

- **Один ПК:** loopback `127.0.0.1` подходит только для процессов на этом компьютере.
- **Разные ПК в LAN:** нужен доступный клиенту HTTPS-вход сервера; LAN-вход Core
  по умолчанию использует порт `8766`, включается явно. Используйте выданное Manager приглашение.
- **Интернет:** настройте отдельный внешний HTTPS-маршрут в Manager и проверьте его
  с другого подключения. Наличие публичного адреса не заменяет одобрение устройства
  и проверку интернет-сессии. Локальный административный API публиковать не нужно.

Подробности реализации: [границы доступа](security.md),
[архитектура](architecture.md), [историческая проверка zrok2](zrok2-verification.md).
Последний документ фиксирует конкретный опыт, а не обещает доступность провайдера сегодня.

## Если возникла проблема

- Проверьте версии обеих сторон и состояние ядра в Manager.
- После отправки всех байтов статус «Проверка файла на сервере» означает, что
  операция ещё завершается; это не готовый файл до подтверждения сервера.
- При ожидающем устройстве проверьте его подтверждение, а при нехватке места —
  квоту пользователя и безопасный запас накопителя.
- Для диска проверьте установленный WinFsp и работающий Client.
- Соберите обезличенные шаги и сообщение ошибки по [SUPPORT.md](../SUPPORT.md).

В b4 не подтверждён минимум 60 МБ/с. Скорость зависит от исходящего канала
сервера, сети клиента, RTT, накопителей, TLS и проверки целостности.
