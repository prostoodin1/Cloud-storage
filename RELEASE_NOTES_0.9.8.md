# Cloud Storage 0.9.8 — Upgrade Log 001

- Системные вкладки остаются кликабельными при выключенном Core и подсвечиваются при наведении.
- В «Настройки» добавлены прямые разделы «Система», «Интерфейс», «Docker» и «SSH».
- Docker и SSH разделены на самостоятельные вкладки с безопасной автонастройкой; контейнеры получили автоматический подбор лимитов.
- Кнопки сохранения скрыты, пока пользователь действительно не изменит настройку.
- Периодический health-check выполняется вне UI-потока и не сбрасывает незаписанные поля.
- Ошибка запуска Core теперь содержит причину Windows/процесса, состояние службы, хвост журнала и путь к полному логу.
- Post-install запуск Server Manager использует ShellExecute, поэтому Windows корректно показывает UAC вместо ошибки CreateProcess 740.
- Manager и Desktop Client используют общий встроенный ICO как runtime-иконку; установщики и EXE продолжают получать тот же ресурс.
- Мобильные зависимости синхронизированы с актуальными patch-версиями Expo SDK 57.
- Сохраняется single-instance защита всех компонентов из 0.9.7.
