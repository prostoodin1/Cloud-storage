# 4. Менеджер на ПК

Server Manager — главное административное приложение: пользователи, подключение по единому коду, накопители, объединённые очереди приёма/отправки, обновления, диагностика и Cloudflare Tunnel. В линейке 0.10.0 выключены фоновые автоматизации; отдельный Container Manager входит в дистрибутив.
