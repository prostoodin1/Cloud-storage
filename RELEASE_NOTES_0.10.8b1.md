# Cloud Storage 0.10.8 beta 1

Бета-версия по Upgrade log #008.

- В Desktop Client и веб-версии добавлена кнопка «Поделиться» рядом с файлами и папками.
- Общая ссылка открывает отдельную безопасную страницу и не раскрывает остальные файлы пространства.
- Для изображений, видео, аудио и текстовых файлов доступен просмотр прямо в браузере; остальные форматы скачиваются.
- Ссылки криптографически случайны, действуют 7 дней, отзываются владельцем и перестают работать после отзыва доступа.
- Виртуальный диск использует локальный staging-кэш: 10 ГБ по умолчанию, с настройкой от 10 до 30 ГБ для каждого сервера.
- При заполнении кэша удаляются старые синхронизированные копии; файлы с неудавшейся загрузкой защищены от очистки.
- Настройки предыдущих версий мигрируют автоматически.

Это beta-релиз для проверки перед стабильным 0.10.8. Мобильные приложения не пересобирались.
