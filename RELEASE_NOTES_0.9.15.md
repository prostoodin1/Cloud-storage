# Cloud Storage 0.9.15

Исправлен вход Desktop Client по ссылке и QR-коду: при таком входе пароль больше не отправляется как пустое значение. Проверка обновлений устойчиво использует актуальное хранилище доверенных сертификатов Windows/CA, не ослабляя TLS-проверку.

Manager получил безопасный вход Google OAuth для Gmail SMTP. Пароль Google не запрашивается и не хранится; для подключения нужен OAuth Client ID из Google Cloud. Настройки предыдущих версий и неизвестные будущие поля сохраняются при обновлении.

Android APK в этом релизе намеренно оставлены без изменений на версии 0.9.14.
