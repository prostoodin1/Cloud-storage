# Cloud Storage 0.7.1 — Interface and update center

Версия исправляет сжатие интерфейса и завершает пользовательский слой этапа 7.

- Все страницы Server Manager и Desktop Client проверены автоматическим визуальным прогоном.
- Настройки получили прокручиваемое содержимое, более компактные боковые панели и крупные элементы.
- Разделы «Права доступа», «Журналы» и «Обновления» теперь содержат реальную информацию.
- Пустые состояния объясняют причину и следующее действие.
- Центр обновлений предлагает ручной режим, автоматическое скачивание или автоматическую установку.
- Можно выбрать стабильный/тестовый канал и конкретную подписанную версию, включая ручной откат.
- Каталог, установщик и повторная проверка перед запуском защищены Ed25519, HTTPS и SHA-256.

Установщики требуют Windows 10 1809+ x64 и права администратора. Настройки, база,
пользователи, токены и пользовательские файлы при обновлении сохраняются.
