# Cloud Storage 0.9.17

Первичное подключение Desktop Client полностью переведено на динамический код из Server Manager. Код автоматически меняется каждые пять минут, содержит подписанные параметры сервера и отклоняется при подделке или истечении срока.

В Client оставлено одно поле «Код подключения». Логин, пароль, ссылка и QR для нового подключения больше не требуются. После успешного pairing клиент безопасно сохраняет токен устройства и в дальнейшем подключается автоматически.

Новое устройство сразу появляется в списке подключённых пользователей как обычный пользователь. В Server Manager его роль можно изменить на администратора.

Существующие подключения и настройки прошлых версий сохраняются. Старый API pairing оставлен только для совместимости с уже выпущенными клиентами.

Android APK не изменялись и остаются на версии 0.9.14.
