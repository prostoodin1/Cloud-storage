# Cloud Storage Native Go Core

`core_go` — нативный системный процесс Cloud Storage, впервые включённый в версию 0.9.9.

Он отвечает за:

- жизненный цикл Windows Service;
- системную single-instance блокировку;
- запуск и контроль внутреннего compatibility engine;
- автоматический перезапуск после сбоя с ограниченной задержкой;
- локальный API-прокси без изменения протокола клиентов;
- очистку устаревших PID-блокировок только после проверки процесса;
- единый UTF-8 журнал и штатное завершение дочерних процессов.

В 0.9.9 функции API v1 продолжают выполняться совместимым Python-модулем на закрытом loopback-порту. Он не является отдельным публичным сервером. Это позволяет переносить маршруты в Go постепенно и сохранять базу, пользователей, файлы, Manager, Desktop Client и мобильные приложения работоспособными.

## Проверка

```powershell
go test ./...
go vet ./...
```

Windows-сборка выполняется `scripts/build-core-go.ps1`. Один и тот же нативный бинарный код выпускается как `CloudStorageServerCore.exe` и `CloudStorageServerService.exe`; второй экземпляр устанавливается в Service Control Manager.
