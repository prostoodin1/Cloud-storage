# Cloud Storage 0.10.3

Исправлено восстановление Desktop Client после изменения адреса сервера и переустановки Core.

- Клиент больше не считает любую ошибку авторизации потерей сети.
- Если DHCP изменил локальный IP, Client находит тот же сервер через LAN discovery, сверяет
  закреплённый TLS-отпечаток и сохраняет новый адрес автоматически.
- Если сохранённый токен отсутствует в новой базе, вместо ложного статуса «Офлайн» показывается
  понятное состояние «Нужно подключить устройство заново» и предлагается новый пятиминутный код.
- Причины потери соединения и автоматическое восстановление адреса записываются в клиентский аудит.
- Каждое подключённое логическое пространство получает фирменную иконку Cloud Storage в Проводнике.
- Размер виртуального диска продолжает отражать реальную квоту пространства с сервера; драйвер не
  подменяет её фиктивным объёмом и не ломает проверку свободного места Windows.

Серверный установщик включает исправление защищённого обновления из 0.10.2 и сохраняет существующие
настройки, базу, пользователей, ключи и файлы.
