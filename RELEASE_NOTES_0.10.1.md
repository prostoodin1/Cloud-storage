# Cloud Storage 0.10.1

Исправлено обновление Cloud Storage Server поверх установленной версии.

- Server Setup теперь сначала закрывает Server Manager и Container Manager, останавливает службу
  и завершает оставшиеся Core-процессы, а уже затем создаёт защищённую резервную копию данных.
- Копирование `core.db`, настроек и серверных ключей повторяется при кратковременной блокировке
  файла антивирусом или завершающимся процессом.
- Исчезающие после корректной остановки SQLite-файлы `-wal` и `-shm` больше не прерывают
  обновление.
- Постоянный установщик переиспользует уже скачанный пакет только после повторной проверки
  размера и SHA-256. Это устраняет попытку заменить запущенный Setup-файл.
- Ошибка занятого установщика теперь локализована и подсказывает закрыть предыдущее окно
  установки вместо показа системного сообщения Windows.

Мобильные приложения в выпуске не изменялись.
