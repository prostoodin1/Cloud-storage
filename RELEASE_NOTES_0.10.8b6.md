# Cloud Storage 0.10.8b6 — графические приложения, восстановление и CLI

Beta для Windows x64. Для обычной работы выберите Client Setup и Server Setup.
CLI — отдельная дополнительная загрузка для автоматизации.
Если b5 уже установлен, новая версия доступна в канале «Стабильные и тестовые».

## Для пользователя

- Сохраняются отдельные графические Client и Server Manager с обычными установщиками.
- Главная страница Manager отдельно показывает готовность хранилища принимать файлы:
  недостаточный безопасный запас места, отключённый накопитель или запрет записи.
- Ошибки нехватки места и недоступности хранилища в клиенте объясняются на русском.
- CLI является дополнительным инструментом для автоматизации, а не заменой интерфейса.

## Ядро

- Метаданные файла и завершение upload-сессии/передачи фиксируются одной SQLite-транзакцией.
- Загрузка восстанавливается после аварийного завершения между rename и фиксацией метаданных.
- Повтор завершения не создаёт лишнюю версию и не подтверждает более новый файл как старую загрузку.
- Поздние ошибки зеркалирования не удаляют уже опубликованные или архивные версии.
- Ошибки I/O, заполнения диска и части ошибок SQLite возвращаются как управляемые 503/507.
- Недоступный диск при уборке не мешает запуску ядра; незавершённые данные сохраняются для повторной попытки.

## CLI

Консольный `CloudStorageCLI.exe`: JSON, состояние сервера, диагностика хранилища,
списки, загрузка с checkpoint, опрос прогресса и скачивание с докачкой/SHA-256.
Секреты не передаются в аргументах и не записываются в checkpoint. Инструкция:
[инструкция CLI](https://github.com/prostoodin1/Cloud-storage/blob/v0.10.8b6/docs/cli.md).

## Ограничения

Новые tus/SFTP/S3/WebDAV ещё не реализованы. Это не полная перепись ядра и не
гарантия отсутствия любых ошибок. Отказы питания/носителя и независимые устройства
через интернет требуют отдельных испытаний. Зависимости mobile не обновлялись.
Установщики не имеют Authenticode-подписи издателя. Исправления не заменяют
настройку доступного хранилища и проверку кабеля/питания физического диска.

Реальная установка/обновление через UAC поверх пользовательской системы не проверялись;
проверки выполнялись на изолированных процессах и портах. Рабочая служба не заменялась.
