# Cloud Storage 0.10.7

Срочное исправление входа через сайт и подключения виртуального диска.

- Веб-вход через настроенный публичный адрес Cloudflare больше не блокируется ошибкой проверки источника запроса.
- Проверка безопасности остаётся строгой: сервер принимает только собственный внутренний адрес и точный публичный адрес из настроек.
- Client после обновления больше не остаётся в административном сеансе Windows.
- Виртуальный диск запускается в обычном сеансе пользователя и виден в Проводнике.
- Сохранены настройки, подключение, учётная запись и назначенные буквы дисков из предыдущей версии.
