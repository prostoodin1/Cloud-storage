# Cloud Storage 0.9.22

Исправления Desktop Client, Manager, Core и виртуального диска Windows.
Мобильные приложения не изменены.

- Client сохраняет открытую папку и выделенный файл при обновлении; запоздалые
  ответы и повторные запросы больше не сбрасывают навигацию.
- Виртуальный диск показывает заданную в Manager квоту и реальное занятое место,
  а не постоянные 8 ТБ. Изменение квоты применяется без повторного подключения.
- В Manager можно выдать динамический код существующему человеку. Браузер и Client
  получают одно и то же пространство, а не разные новые личные диски.
- Исправлен полный отзыв доступа, включая последний виртуальный диск, завершение
  загрузки после отзыва прав и публичные ссылки пользователя без права делиться.
- В Manager добавлены удаление виртуального диска в архив и восстановление.
  Физические файлы не удаляются; публичные ссылки при архивации отзываются.
- Карточки личных дисков показывают владельца и позволяют открыть настройку квоты.
- Сайт устойчив к запоздалым ответам и показывает фактические квоты. Manager
  различает локальный адрес сайта и настроенный интернет-адрес.

Существующие настройки, пользователи и файлы сохраняются миграцией SQLite.
Для кодов существующего человека обновите сервер и Desktop Client вместе.

Проверены Python/Go тесты, настоящий WinFSP-диск и сайт в браузере на изолированном
сервере: загрузка, скачивание с совпадением SHA-256, переименование, повторный вход,
квоты, права, архив и восстановление. Это не проверка всех внешних интеграций:
новый прогон из отдельной интернет-сети, SMTP/Gmail и Docker не выполнялся.
Подробности: `docs/FIXES-AFTER-0.9.21.md`.
