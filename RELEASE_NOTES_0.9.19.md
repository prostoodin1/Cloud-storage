# Cloud Storage 0.9.19

Выполнены Upgrade Log #003 и Upgrade Log #005.

В Server Manager динамический код подключения расположен первым. Список пользователей
сворачивается и показывает дату создания, последний вход, состояние цветной точкой и
текущую файловую операцию с исходным и целевым путём. Удаление пользователя отключено
как в интерфейсе, так и отдельным запретом административного API; учётную запись можно
безопасно отключить с сохранением файлов и аудита.

Вкладка дисков получает подтверждённые Windows-показатели: модель, серийный номер,
интерфейс, фактические общий/занятый/свободный объёмы, текущую нагрузку и скорости
чтения/записи. Недоступные SMART-показатели не выдумываются. Системный том виден для
диагностики, но защищён от назначения хранилищем и опасных действий; виртуальные диски
Client и Google Drive исключены из списка физических накопителей.

Для каждого физического диска можно массово применить подробные права пользователей ко
всем его общим логическим пространствам. Меню «Действия» открывает диск в Проводнике,
запускает проверку ошибок и штатную оптимизацию Windows. Удаление диска из Manager не
стирает данные. Форматирование доступно только для несистемного и отключённого от
Cloud Storage тома, требует отдельного предупреждения и ручного ввода контрольной строки.

Ошибки доступа к каталогу управляемого диска теперь возвращаются как понятная ошибка
настройки вместо HTTP 500. Существующие база, настройки, пользователи и файлы сохраняются
при обновлении. Android APK не изменялись и остаются на версии 0.9.14.
